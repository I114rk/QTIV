QTIV — Qt Image Viewer

Просмотрщик изображений: смотреть, сравнивать, зумить, конвертировать и хранить несколько фото в одном файле открытого формата .qtivp. Интерфейс на русском и английском, тёмная тема.

Просмотр и управление

Откройте фото через Ctrl+O, двойной клик в файловом менеджере или перетащите файлы в окно. Если открыть один файл, его папка становится плейлистом (как в видеоплеерах): стрелки ←/→ листают все фото из папки. Если выделить несколько файлов — плейлист будет ровно из них.

Зум — колесом мыши (к курсору), до 64×. Перетаскивание — панорамирование. Двойной клик переключает «вписать в окно» / «1:1». Внизу — лента миниатюр: клик или стрелки внутри ленты переключают фото (клавиша T скрывает/показывает ленту), а если миниатюры не помещаются — лента прокручивается колесом мыши. Миниатюры группируются по файлам-источникам: записи одного альбома .qtivp идут единой группой, обычные фото разделяются между собой линией. Прозрачность видна на шахматном фоне, ориентация EXIF учитывается автоматически.

Поддерживаются JPG, PNG, WebP, AVIF, BMP, GIF, TIFF, HEIC и ещё ~30 форматов.

Сравнение фото

Нажмите F12 (или клавишу C, кнопку на панели инструментов, пункт меню «Вид → Сравнение») — откроются две панели рядом. Нужно не менее двух фото в плейлисте.

  • Выбор фото — выпадающий список над каждой панелью.
  • + панель / − панель — от 2 до 8 изображений одновременно (граница — «минус»).
  • Sync: on (клавиша S) — синхронные зум и панорамирование всех панелей: удобно сравнивать фрагменты пиксель в пиксель.
  • Разделитель панелей можно перетаскивать. Esc — закрыть сравнение.

Из консоли — сразу в сравнение:

qtiv -comp before.jpg after.jpg      # сравнить ровно эти фото
qtiv -comp -n=3 album.qtivp          # 3 фото из альбома
qtiv -comp -n=4 ~/Photos/            # 4 фото из папки

Конвертация и альбомы

Ctrl+S — конвертировать текущее фото (PNG / JPEG / WebP / AVIF / BMP, с качеством). Ctrl+Shift+S — экспорт всего плейлиста: либо каждый файл в выбранный формат, либо всё в один альбом .qtivp (фото складываются без перекодирования — байт в байт, без потери качества).

Ctrl+Shift+E — извлечь открытый альбом в папку. Ctrl+Shift+O — открыть альбом .qtivp как плейлист: каждое фото альбома — отдельный элемент.

Консоль: qtiv -c и другие команды

qtiv -c file.png показывает изображение прямо в терминале. Возможности терминала определяются автоматически:

  • kitty graphics — настоящее фото пиксель в пиксель: kitty, WezTerm, Ghostty, Konsole;
  • sixel — foot, xterm, mintty и другие;
  • полублоки ▀ — цветной «пиксель-арт» из символов: почти все современные терминалы (внутри tmux используется именно этот режим);
  • ASCII-арт — самый простой терминал или вывод в файл/пайп.

Режим можно задать явно: qtiv -c --kitty f.png, --sixel, --half, --ascii. Остальные команды:

qtiv --info FILE          # JSON: размеры, формат или состав альбома
qtiv --pack OUT FILES...  # упаковать фото в альбом .qtivp
qtiv -comp A B            # GUI сразу в режиме сравнения
qtiv -comp -n=K FILE      # GUI: сравнить K фото из альбома/папки

Формат .qtivp

.qtivp (QT Image Viewer Photo) — открытый контейнерный формат для хранения нескольких фото в одном файле. Спецификация передана в общественное достояние (CC0): любой может реализовать её в своём ПО бесплатно и без разрешения. Полный документ: docs/QTIVP-SPEC.md в репозитории QTIV.

Структура файла (little-endian):

  • заголовок 16 байт: сигнатура QTIVP1\0\0, версия, счётчик записей;
  • индекс: для каждого фото — имя (UTF-8), MIME-тип, размеры, смещение, флаг сжатия, CRC32;
  • данные: исходные байты файлов (JPEG кладётся как есть), опционально сжатые zlib.

Фото хранятся без перекодирования. Целостность каждой записи проверяется контрольной суммой CRC-32 (полином zlib). Независимая реализация формата на Python входит в тесты проекта (tests/qtivp_check.py) — формат верифицирован в обе стороны.

Инструмент qtivp

Отдельная консольная утилита для работы с альбомами — упаковка и распаковка без GUI:

qtivp -compress photos.qtivp photo1.png photo2.png ... photo100.png
qtivp -compress photos.qtivp photo*.*          # оболочка раскроет маску
qtivp -compress vacation.qtivp ~/Pictures/sea/ # папка целиком
qtivp -extract photos.qtivp ~/out              # распаковать байт в байт
qtivp -list photos.qtivp                       # состав альбома
qtivp -test photos.qtivp                       # проверка CRC всех записей

-compress принимает изображения, готовые альбомы .qtivp (их записи объединяются) и целые папки. Сжатие zlib применяется тогда, когда оно реально уменьшает данные. -extract восстанавливает файлы байт в байт; существующие файлы не перезаписываются — добавляется суффикс -1, -2…
