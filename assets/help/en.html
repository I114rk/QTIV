QTIV — Qt Image Viewer

An image viewer: browse, compare, zoom, convert and store several photos in a single file of the open .qtivp format. Russian and English interface, dark theme.

Viewing and navigation

Open a photo with Ctrl+O, by double-clicking it in your file manager, or by dropping files onto the window. Opening a single file makes its folder the playlist (like in media players): the ←/→ keys flip through every photo in that folder. Selecting several files makes the playlist exactly those files.

Zoom with the mouse wheel (towards the cursor), up to 64×. Drag to pan. Double-click toggles “fit to window” / “1:1”. At the bottom there is the thumbnail strip: clicking a thumbnail or using arrows inside the strip switches photos (press T to hide or show it); when the thumbnails do not fit, the strip is scrolled with the mouse wheel. Thumbnails are grouped by source file: entries of one .qtivp album form a single group, regular photos are separated by a line. Transparency is shown over a checkerboard, EXIF orientation is applied automatically.

Supported formats: JPG, PNG, WebP, AVIF, BMP, GIF, TIFF, HEIC and about 30 more.

Comparing photos

Press F12 (or the C key, the toolbar button, or the “View → Compare” menu item) — two panels open side by side. At least two photos in the playlist are required.

  • Choosing photos — a drop-down list above each panel.
  • + panel / − panel — from 2 to 8 images at once.
  • Sync: on (the S key) — synchronized zoom and panning across all panels: handy for comparing fragments pixel by pixel.
  • The splitter between panels is draggable. Esc closes compare mode.

From the terminal — straight into compare mode:

qtiv -comp before.jpg after.jpg      # compare exactly these photos
qtiv -comp -n=3 album.qtivp          # 3 photos from an album
qtiv -comp -n=4 ~/Photos/            # 4 photos from a folder

Conversion and albums

Ctrl+S converts the current photo (PNG / JPEG / WebP / AVIF / BMP, with a quality setting). Ctrl+Shift+S exports the whole playlist: either every file into the chosen format, or everything into a single .qtivp album (photos are stored without re-encoding — byte for byte, no quality loss).

Ctrl+Shift+E extracts the opened album into a folder. Ctrl+Shift+O opens a .qtivp album as a playlist: every photo of the album becomes a separate item.

Terminal: qtiv -c and other commands

qtiv -c file.png shows the image right in the terminal. Terminal capabilities are detected automatically:

  • kitty graphics — a real pixel-perfect image: kitty, WezTerm, Ghostty, Konsole;
  • sixel — foot, xterm, mintty and others;
  • halfblocks ▀ — colored “pixel art” from characters: almost any modern terminal (this mode is used inside tmux);
  • ASCII art — the simplest terminal, or when output goes to a file or a pipe.

The mode can be forced: qtiv -c --kitty f.png, --sixel, --half, --ascii. Other commands:

qtiv --info FILE          # JSON: dimensions, format or album contents
qtiv --pack OUT FILES...  # pack photos into a .qtivp album
qtiv -comp A B            # GUI straight into compare mode
qtiv -comp -n=K FILE      # GUI: compare K photos of an album/folder

The .qtivp format

.qtivp (QT Image Viewer Photo) is an open container format for storing several photos in one file. The specification is dedicated to the public domain (CC0): anyone may implement it in their software, free of charge and without permission. The full document: docs/QTIVP-SPEC.md in the QTIV repository.

File structure (little-endian):

  • a 16-byte header: the QTIVP1\0\0 signature, version, entry count;
  • an index: for every photo — name (UTF-8), MIME type, dimensions, offset, compression flag, CRC32;
  • data: the original file bytes (a JPEG is stored as is), optionally compressed with zlib.

Photos are stored without re-encoding. The integrity of every entry is verified with a CRC-32 checksum (the zlib polynomial). An independent Python implementation is part of the project tests (tests/qtivp_check.py) — the format is verified in both directions.

The qtivp tool

A separate console utility for working with albums — packing and unpacking without the GUI:

qtivp -compress photos.qtivp photo1.png photo2.png ... photo100.png
qtivp -compress photos.qtivp photo*.*          # the shell expands the glob
qtivp -compress vacation.qtivp ~/Pictures/sea/ # a whole folder
qtivp -extract photos.qtivp ~/out              # extract byte for byte
qtivp -list photos.qtivp                       # album contents
qtivp -test photos.qtivp                       # verify CRC of every entry

-compress accepts images, ready .qtivp albums (their entries are merged) and whole folders. zlib compression is applied only when it actually shrinks the data. -extract restores files byte for byte; existing files are never overwritten — a -1, -2… suffix is added instead.
