# QTIV — Qt Image Viewer

Просмотрщик изображений на C++20 / Qt6: смотреть, **сравнивать**, зумить,
**конвертировать** и хранить несколько фото в одном файле открытого формата
**`.qtivp`**. Тёмная тема, интерфейс на русском и английском (переключение на
лету), установка пакетом через `makepkg`.

```
qtiv photo.jpg              # папка фото → плейлист, фото — в фокусе
qtiv a.jpg b.png c.webp     # плейлист ровно из этих файлов
qtiv album.qtivp            # альбом как плейлист
qtiv -c photo.png           # показать фото прямо в терминале
qtiv -comp before.jpg after.jpg   # сразу в режим сравнения
qtiv -comp -n=3 album.qtivp # сравнить 3 фото из альбома
qtivh                       # GUI-руководство (или F1 в QTIV)
qtivp -compress photos.qtivp photo*.*   # упаковать фото в альбом
qtivp -extract photos.qtivp ~/out      # распаковать альбом
```

## Возможности

- **Просмотр** — зум колесом к курсору (до 64×), панорамирование
  перетаскиванием, «по размеру окна» / «1:1» (двойной клик переключает),
  шахматный фон под прозрачностью, учёт EXIF-ориентации.
- **Плейлист** — папка открытого файла (как в видеоплеерах), лента миниатюр
  снизу (генерируется в фоне; клик и стрелки внутри ленты переключают
  фото; прокрутка колесом, когда не помещаются), навигация
  стрелками/PgUp/PgDn/Home/End, переход к номеру, drag&drop.
  Миниатюры группируются по файлам-источникам: записи одного альбома
  `.qtivp` идут единой группой, обычные фото разделяются линией.
- **Сравнение (F12)** — от 2 до 8 изображений рядом, **синхронные зум и
  панорамирование**, выбор фото для каждой панели, сплиттер можно двигать.
  Из консоли: `qtiv -comp a.png b.png` или `qtiv -comp -n=3 album.qtivp`.
- **Форматы** — JPG, PNG, WebP, AVIF, BMP, GIF, TIFF, HEIC и ещё ~30
  (всё, что даёт Qt + плагин qt6-imageformats).
- **Конвертация (Ctrl+S / Ctrl+Shift+S)** — текущее фото или весь плейлист
  в PNG / JPEG / WebP / AVIF / BMP с настройкой качества.
- **`.qtivp`** — открытый контейнер: несколько фото в одном файле **без
  перекодирования**. Упаковка, распаковка, чтение из CLI. Полная
  спецификация: [docs/QTIVP-SPEC.md](docs/QTIVP-SPEC.md).
- **Инструмент `qtivp`** — работа с альбомами из консоли: `-compress`
  (упаковать фото, альбомы и целые папки), `-extract` (распаковать байт в
  байт), `-list` (содержимое), `-test` (проверка CRC всех записей).
- **Терминал (`qtiv -c`)** — настоящее фото в терминале: kitty graphics
  (kitty, WezTerm, Ghostty, Konsole), sixel (foot, xterm, mintty), при
  отсутствии протоколов — цветные полублоки, а в самом простом случае —
  ASCII-арт. Возможности терминала определяются автоматически (внутри
  tmux используются полублоки).
- **Руководство (`qtivh` / `F1`)** — GUI-руководство на русском и
  английском: просмотр, сравнение, консольный режим, формат `.qtivp` и
  инструмент `qtivp`. Отдельный бинарник `qtivh` или `F1` из QTIV.
- **Два языка интерфейса** — Русский / English / Системный, переключение
  на лету без перезапуска.
- **Настройки сохраняются** — язык, геометрия окна, последний каталог,
  видимость миниатюр, синхронный зум, формат и качество экспорта
  (`~/.config/QTIV/QTIV.conf`).

## Горячие клавиши

| Клавиши            | Действие                              |
|--------------------|---------------------------------------|
| `←` / `→`, `PgUp` / `PgDn` | предыдущее / следующее фото   |
| `Home` / `End`     | первое / последнее фото               |
| колесо мыши        | зум к курсору                         |
| `+` / `−`          | зум                                   |
| `F`                | по размеру окна                       |
| `Ctrl+1`           | реальный размер (1:1)                 |
| двойной клик       | переключить «вписать» / «1:1»         |
| `F12` или `C`      | режим сравнения                       |
| `+ панель` / `− панель` | добавить/убрать панель (в сравнении) |
| `S`                | вкл/выкл синхронизацию (в сравнении)  |
| `T`                | лента миниатюр                        |
| колесо над лентой  | прокрутка ленты миниатюр              |
| `F11`              | полный экран                          |
| `F1`               | руководство (qtivh)                   |
| `Ctrl+O`           | открыть файлы                         |
| `Ctrl+Shift+O`     | открыть альбом .qtivp                 |
| `Ctrl+S`           | конвертировать текущее фото           |
| `Ctrl+Shift+S`     | экспорт плейлиста / упаковка альбома  |
| `Ctrl+Shift+E`     | извлечь альбом в папку                |
| `Ctrl+Q`           | выход                                 |

## CLI

```
qtiv [FILES...]            GUI: изображения, папки или альбомы .qtivp
qtiv -c, --cat FILES...    показать в терминале (авто-режим)
    --ascii                форсировать ASCII-арт
    --half                 форсировать полублоки
    --sixel                форсировать sixel
    --kitty                форсировать kitty graphics
qtiv -comp [FILES...]      сразу режим сравнения (2 панели)
qtiv -comp -n=K FILE       сравнить K фото из альбома/папки
qtiv --info FILE           JSON с информацией об изображении или альбоме
qtiv --pack OUT FILES...   упаковать изображения/альбомы в .qtivp
qtiv --help | --version
```

### qtivp — инструмент альбомов

```
qtivp -compress OUT FILES...   упаковать фото/альбомы/папки в альбом
qtivp -extract ALBUM [DIR]     распаковать альбом (байт в байт)
qtivp -list ALBUM              показать содержимое
qtivp -test ALBUM              проверить структуру и CRC каждой записи
```

### qtivh — GUI-руководство

```
qtivh                          # руководство на русском или английском
```

То же окно открывается из QTIV по `F1` (меню «Справка»). Внутри:
просмотр, сравнение, консольный режим (`qtiv -c`), формат `.qtivp`
и инструмент `qtivp`; язык переключается на лету.

Примеры:

```console
$ qtiv --info examples/demo.qtivp | python -m json.tool
$ qtiv -comp -n=3 examples/demo.qtivp
$ qtiv -c --sixel sunset.png
$ qtivp -compress photos.qtivp photo1.png photo2.png photo100.png
$ qtivp -compress photos.qtivp photo*.*
$ qtivp -extract photos.qtivp ~/out && qtivp -test photos.qtivp
```

## Сборка

Зависимости: `qt6-base`, `qt6-imageformats`, `qt6-svg`, `cmake`, `ninja`
(для тестов — `python`, для пакета — `base-devel`).

```console
$ cmake -B build -GNinja -DCMAKE_BUILD_TYPE=Release
$ cmake --build build
$ ctest --test-dir build     # unit-тесты формата + интероп с Python
$ ./build/qtiv examples/demo.qtivp
```

## Установка (Arch Linux / makepkg)

```console
$ cd packaging
$ makepkg -si
```

`makepkg` соберёт и установит пакет: бинарники `/usr/bin/qtiv`,
`/usr/bin/qtivp` и `/usr/bin/qtivh`, `.desktop`-файлы с MIME-ассоциациями
(двойной клик по jpg/png/webp/avif/.qtivp открывает
QTIV), MIME-тип `application/x-qtivp`, иконку hicolor.

> **Примечание:** PKGBUILD клонирует репозиторий через git — перед `makepkg`
> зафиксируйте изменения (`git add -A && git commit`).

## Формат .qtivp — открытый

`.qtivp` — открытый контейнерный формат: 8-байтовая сигнатура `QTIVP1`,
индекс записей (имя, MIME, размеры, смещения, CRC32), опциональное
zlib-сжатие, фото хранятся без перекодирования. Спецификация в общественном
достоянии: **[docs/QTIVP-SPEC.md](docs/QTIVP-SPEC.md)**, независимая
реализация на Python — `tests/qtivp_check.py`.
